# Anaconda / Jupyter Notebooks

This directory is reserved for the original Anaconda/Jupyter notebooks used during early model development, including LSTM and Random Forest experiments.

The notebooks are not yet present in the repository because they remain on the local development machine.

Recommended files to add here:
- the original LSTM training notebook
- Random Forest comparison notebook
- Kaggle / preprocessing experiments
- confusion-matrix and train/test analysis notebooks

Once copied into this folder, commit them with a message such as:

```bash
git add notebooks/
git commit -m "Add original Anaconda model-development notebooks"
git push origin main
```
